## 🌐 Deploying to Netlify

This repository is pre-configured with `netlify.toml` and `public/_redirects` for automatic build and SPA route handling.

### Method 1: Automatic Deployment via Netlify Dashboard (Recommended)

1. Log in to [Netlify](https://app.netlify.com/).
2. Click **"Add new site"** $\rightarrow$ **"Import an existing project"**.
3. Select **GitHub** and authorize access to `kavyashah3011/carboard`.
4. Netlify will auto-detect settings from `netlify.toml`:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
5. Click **"Deploy carboard"**. Netlify will build and deploy your site in ~1 minute!
